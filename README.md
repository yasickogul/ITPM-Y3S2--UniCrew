# UniCrew - Discussion Board Module

Welcome to the **UniCrew Discussion Board**, a high-performance community platform for students.

## 🚀 Overview

This project provides a fully-featured discussion board with AI-powered moderation, quality analysis, and smart categorization.

- **Backend**: Node.js, Express, MongoDB
- **AI**: Custom algorithms for content analysis and metadata generation
